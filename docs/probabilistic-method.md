# 概率化方法（v1）

## 数据源

[Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) — 免费、无需 key、覆盖全球。提供基于 CAMS / 各国家模型的**确定性点预测**（即每小时只给一个数值，没有不确定性信息）。

PM2.5 的有效预报窗口约 5-6 天，第 7 天的数据通常缺失。

## v1：合成集合（Synthetic Ensemble）

因为上游只给点预测，我们在本地用蒙特卡洛模拟合成一个伪集合：

1. 对每个城市、每个未来日：把当日 24 小时的 PM2.5 点预测取平均，作为该日的中心值 `μ`
2. 设定标准差：`σ = max(8, μ × 0.20 × (1 + 预报天数 × 0.15))`
   - 基础相对误差 20%（PM2.5 短期预报的经验量级）
   - 每延后一天扩大 15%（误差随时长增长是大气模型的普遍规律）
   - 下限 8 µg/m³，避免极低浓度下区间过窄
3. 从 `N(μ, σ²)` 采样 1000 次，每个样本截断到 ≥ 0（PM2.5 物理量非负）
4. 落入 6 个中国 AQI 等级桶（GB 3095-2012 24h 均值断点），得到每个等级的概率
5. 从样本排序中取 10% / 50% / 90% 分位数，作为 UI 显示的「区间」

随机种子由城市名 hash + 天偏移决定，所以同一天对同一城市跑两次结果完全一致（reproducible）。

## v1 的局限

- **不是真实集合预报**。真实集合是同一物理模型用扰动初始条件跑 N 次得到 N 个不同的预测；我们这里是单点预测加合成噪声。两者数学上不等价。
- **σ 是先验固定的**，不会自适应。如果模型在某城市某季节系统性高估，区间宽度还是按 20% 来，不会拉宽。
- **σ 假设高斯分布**。PM2.5 真实误差分布常常右偏（污染峰值时低估更严重），高斯化会低估极端等级的概率。
- **未做偏差校正**。模型的系统性偏差（例如 Open-Meteo 在中国华北可能整体偏低）没有修正。

UI 上显式标注「概率为统计估计，仅供参考」，避免误用。

## v2 改进路线

按优先级排：

1. **滚动残差校正**：累积近 30 天 (predicted, observed) 对，按城市分别拟合 σ；用滑动平均把 σ 从经验先验切到数据驱动
2. **分位数回归**：直接训练一个 quantile loss 模型预测 P10/P50/P90，比假设高斯更稳健
3. **真实集合数据源**：接入 CAMS 集合预报（需付费），或 NOAA GFS 的全球空气质量集合
4. **加 O3 / NO2**：对夏季臭氧污染的预报需求高
5. **偏差校正**：滑动平均 (mean predicted - mean observed) 作为 offset 加到 μ 上

## 验证 v1 是否合理的清单

- ✅ 单个采样分布看起来对称、围绕 μ
- ✅ P10 ≤ P50 ≤ P90 严格成立
- ✅ 6 类概率和为 1
- ✅ 预报天数越长，分布越宽（验证 σ 随 lead day 增长）
- ✅ 高污染日（μ 大）的高等级概率显著高于低污染日

实际生产时还应定期对比模型输出与实测，例如每周看一次「预报为 60% 良 实际是良」的频率，做后验校准检查。
